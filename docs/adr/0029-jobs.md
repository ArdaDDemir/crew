# Jobs are hidden workspace slots, not People

## Context and Problem Statement

Title, compact, vision, and read need a cheap model (and optionally a Soul) without adding rail People or waking a channel member. Per-person models already cover talk. Compact (`ADR-0028`) already reads `jobs.compact.model`. There was no store, HTTP, or Settings UI.

## Decision Drivers

- Jobs are faceless workers. They are not People and do not get rail entries.
- JSONL stays append-only (`ADR-0004`). Titles append `thread.titled`; they do not rewrite.
- Title is not a channel wake (`ADR-0013`).
- Empty vision/read model means skip. Empty title/compact model means the workspace default.
- Config PATCH must not wipe jobs. Prefer `.crew/jobs.json` over `config.json`.

## Considered Options

- Extra People (Title, Compact) on the rail with reserved ids.
- `config.json` `jobs` key.
- Workspace slots in `.crew/jobs.json` + Settings Jobs.

## Decision Outcome

Chosen option: **workspace job slots** in `.crew/jobs.json`.

Shape:

```json
{
  "title": { "model": "", "botId": null },
  "compact": { "model": "", "botId": null },
  "vision": { "model": "", "botId": null },
  "read": { "model": "", "botId": null }
}
```

- `GET` / `PUT /api/jobs`. `botId` is null or an existing bot, never a reserved id.
- Optional `botId` wraps the one-shot prompt with that person's Soul. They are not woken.
- Title: after the first human post on a human DM, append `thread.titled` `{ title, description, model, botId }`. `POST /api/thread-title` regenerates (last wins). Direct list prefers the latest titled title.
- Vision: caption attached `png|jpg|jpeg|webp|gif` when the vision model is set; prepend `[image path: CAPTION]`. Failure keeps path-only.
- Compact: `summarizeThread` uses `compact.model` and optional Soul wrap.
- Read: stored; v1 may skip running it.

### Consequences

- Good, because cheap workers stay off the People rail.
- Good, because titles live in JSONL and can be regenerated without rewriting history.
- Bad, because a bad title model still writes an event (fallback is the first 48 chars).
- Out of this ADR: computer-use, CLI TUI, waking a job as a Person.

### Confirmation

`.crew/jobs.json`, `GET`/`PUT /api/jobs`, `POST /api/thread-title`, `apps/web/src/jobs.ts`, Settings `#jobs-section`, `docs/specs/web-ui.md`, `docs/specs/session-jsonl.md`.
