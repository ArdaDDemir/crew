## Compact (shipped, ADR-0028)

Three append-only layers. JSONL never rewritten. UI still shows the full thread.

1. **Window** — last 80 `message.posted`, append `thread.compacted` `{keptFrom, dropped}` (`ADR-0019`).
2. **Trim** — `buildHistory` uses posted only; no `tool.completed` dumps.
3. **LLM summary** — cheap compact job; append `thread.summary` `{text, keptFrom, model, botId}`. Prompt = summary + last N. Disk/JSONL stay.

UI: `/compact`, `#context-chip` `{posted}/{keep}` · `compacted`, auto at ~70% of keep once per thread. `/clear` is a session hide, not truncate.

Do **not** use an xAI opaque compaction blob as source of truth.
